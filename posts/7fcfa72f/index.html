JADX 接入 AI：jadx-mcp 极简教程

本文介绍如何在 JADX 中安装 jadx-ai-mcp 插件并配置 MCP 服务，让 AI 能够直接读取和分析反编译后的代码。

一、下载 JADX-GUI

从 GitHub 下载最新版 jadx-gui（含 JRE 的 Windows 版本）：

https://github.com/skylot/jadx/releases/download/v1.5.6/jadx-gui-1.5.6-with-jre-win.zip

二、安装插件

  1. 打开 JADX，进入 插件 -> 管理插件：

  1. 在列表中选择并安装 jadx-ai-mcp：

插件 jar 也可以从 GitHub 直接下载（在 JADX 中直接安装，或下载到本地后导入）：

https://github.com/zinja-coder/jadx-ai-mcp/releases/download/V6.4.1/jadx-ai-mcp-6.4.1.jar

三、下载并解压 MCP 服务脚本

https://github.com/zinja-coder/jadx-ai-mcp/releases/download/V6.4.1/jadx-mcp-server-6.4.1.zip
